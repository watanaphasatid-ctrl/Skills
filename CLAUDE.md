## K.M. automatic skill selection

For substantial engineering or software tasks, check the Skills available **in this session** and automatically apply the most relevant 1-3 where supported. Prefer the `km-auto-skill-router` procedure for Niagara N4, Java, BMS/PLC, debugging, code review, testing, UI, security, and document workflows. Do not require the user to type a slash command for ordinary requests.

Treat names in GitHub as **not installed** until this session can actually see/use them. Avoid duplicate workflows. State `Skills used: ...` only when Skills were genuinely loaded and applied. Never invent build/test results or edit unrelated project code. Any destructive operation or privileged action must stay inside approved scope.
